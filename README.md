# Super Info Products (SIP) - React + Tailwind

A modern recreation of [superinfoproducts.site](https://superinfoproducts.site/) built with React and Tailwind CSS.

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Styling

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
